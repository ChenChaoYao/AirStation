# 電壓及車內空氣狀態監督站 (Car Battery & Air Status Monitor)

基於 **ESP32** 與 **LVGL 8.3** 的高即時性電壓與車內空氣品質綜合監督站。

---

## 🚀 專案特點

1. **中文圖形介面 (LVGL 8.3 + 專屬中文字型)**：
   - 採用專屬生成的 16px 與 20px CJK 中文字型，顯示純繁體中文標籤。
   - 雙頁面動態切換：
     - **畫面一（電力與大氣狀態）**：即時/最高/最低電壓、即時/最高/最低溫度、大氣壓力（hPa）、海拔高度（m）、ESP-NOW 連線設備數與累積接收封包數。
     - **畫面二（車內空氣品質）**：CO2 二氧化碳濃度 (ppm)、TVOC 總揮發性有機物 (mg/m³)、CH2O 甲醛濃度 (mg/m³)，搭配安全/超標動態雙色進度條。
2. **極速即時觸控反應**：
   - 全面重構主循環（`loop`）為非阻塞式微任務架構（200Hz 輪詢），移除傳統阻塞延遲（`delay(800)`）。
   - 移除觸控中斷中的 Serial 阻塞列印，點擊即時響應（< 10ms），並縮短頁面切換過渡動畫至 200ms。
3. **無線遙測 (ESP-NOW)**：
   - 透過 ESP-NOW 點對多點接收遠端發射端節點的電池電壓與環境溫濕度，內建 CheckSUM 校驗與多設備 MAC 動態記錄。
4. **環境與空氣品質感測**：
   - **BMP180 氣壓感測器**：I2C 讀取大氣壓力並依據國際標準大氣結合現場溫度換算精確海拔高度。
   - **JW01 一體化感測器**：軟體序列埠即時接收並解析 CO2、TVOC 與甲醛數據。
5. **警報防護機制**：
   - 電壓低於 12.5V 自動觸發紅色 LED 警報，正常時藍綠 LED 交替跳動。

---

## 🛠️ 硬體架構

- **主控晶片**：ESP32 Dev Module
- **螢幕規格**：2.8 吋 SPI TFT LCD (240x320)
- **觸控晶片**：XPT2046 電阻觸控 (TFT_Touch)
- **感測模組**：
  - BMP180 氣壓高度感測器 (I2C: SDA 22, SCL 27)
  - JW01 空氣品質感測器 (UART: RX 35, 9600bps)
  - RGB 狀態指示燈 (Red: 4, Green: 16, Blue: 17)

---

## 📦 建置與燒錄

專案採用 [PlatformIO](https://platformio.org/) 開發管理：

```bash
# 編譯專案
pio run

# 燒錄至開發板 (USB 連接)
pio run -t upload

# 監看序列埠輸出 (115200 bps)
pio device monitor
```
